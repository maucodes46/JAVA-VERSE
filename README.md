# JavaVerse

A structured Java learning repository for academic growth, practical study, and professional portfolio presentation.

JavaVerse is organized to reflect a university Java learning journey across fundamentals, object-oriented programming, lab work, JavaFX, and project-based practice. The repository is intentionally clean, beginner-friendly, and ready for ongoing coursework and future additions.

## Learning Goals

- Build a clear understanding of Java fundamentals
- Organize academic Java learning in a professional structure
- Maintain a dedicated space for university lab work
- Explore object-oriented programming concepts systematically
- Track JavaFX learning and GUI development progress
- Keep a clean portfolio-ready repository for future work
- Preserve a simple structure that is easy to expand over time
